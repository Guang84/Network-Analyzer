# ---------------------------------------------------------------------------
# REQUIRED SYSTEM TOOLS (not installable with pip)
# ---------------------------------------------------------------------------
# Debian / Ubuntu / Kali:
#   sudo apt update
#   sudo apt install python3 python3-venv python3-pip aircrack-ng iw \
#       iproute2 tmux ethtool sudo rfkill procps
#
# Commands supplied by those packages:
#   aircrack-ng  -> airmon-ng, airodump-ng, aireplay-ng, aircrack-ng
#   iw           -> wireless capability, mode, channel, and interface control
#   iproute2     -> ip link state control
#   tmux         -> multi-terminal dashboards and application cleanup
#   ethtool      -> wireless-driver identification
#   sudo         -> privileged wireless operations when not running as root
#   rfkill       -> Wi-Fi unblock during network-state recovery
#   procps       -> ps, pgrep, and watch process/status views
#
# A graphical terminal is optional. Install one to show live airodump-ng in a
# separate window, for example:
#   sudo apt install xterm
# Supported alternatives include gnome-terminal, konsole, xfce4-terminal,
# mate-terminal, lxterminal, tilix, kitty, alacritty, and foot. Without one,
# live commands run in the current terminal.
#
# Network restoration uses the manager already installed by the operating
# system. Supported commands include nmcli (NetworkManager), iwctl (iwd),
# connmanctl (ConnMan), and wpa_cli (wpa_supplicant). Only the manager actually
# used by the host is needed.
